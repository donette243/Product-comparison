
# Product Comparison — Семантическое сопоставление товаров с использованием NLP

## Описание проекта

**Product Comparison** — система автоматизированного поиска и сопоставления похожих товаров из разных каталогов электронной коммерции с использованием методов обработки естественного языка (NLP), моделей семейства Transformer и семантического анализа текстовых данных.

Проект направлен на решение задачи сопоставления товарных позиций (Product Matching) на основе названий, описаний и характеристик товаров.

Система преобразует текстовую информацию в векторные представления (embeddings), вычисляет семантическое сходство между товарами и определяет наиболее близкие позиции в разных каталогах.

Для демонстрации используются два синтетических каталога, моделирующих ассортимент Ozon и Wildberries.

## 1. Цель проекта

Разработка алгоритма автоматизированного сопоставления товаров из разных источников на основе семантического сходства текстовых описаний.

Основные задачи:

- Генерация и подготовка товарных каталогов.
- Обработка названий, описаний и характеристик товаров.
- Преобразование текстов в embeddings с использованием SentenceTransformers.
- Вычисление косинусного сходства между товарными позициями.
- Поиск наиболее релевантных соответствий между каталогами.
- Ранжирование найденных соответствий по степени сходства.
- Сохранение результатов анализа.
- Визуализация распределения показателей семантического сходства.

## 2. Функциональные возможности

### 2.1. Генерация товарных каталогов

Система формирует два независимых синтетических каталога по 60 товаров.

Каждый товар содержит:

- Название.
- Бренд и модель в составе названия.
- Текстовое описание.
- Дополнительные характеристики.

Для генерации используются различные категории электроники, включая смартфоны, ноутбуки, планшеты, мониторы и другие устройства.

### 2.2. Предобработка текстовых данных

Для каждого товара создаётся единое текстовое представление, объединяющее:

- Название товара.
- Описание.
- Технические характеристики.

Объединённый текст используется для построения семантического представления товара.

### 2.3. Создание текстовых embeddings

Для преобразования текстовых описаний в числовые векторы используется библиотека SentenceTransformers с локально загружаемой моделью.

Векторные представления позволяют сравнивать товары на основе семантических характеристик текстов.

### 2.4. Семантическое сопоставление товаров

Для сравнения векторных представлений применяется косинусное сходство (Cosine Similarity).

Система вычисляет матрицу сходства между товарами двух каталогов и для каждой позиции первого каталога определяет наиболее похожую позицию второго каталога.

Результаты включают:

- Название товара первого каталога.
- Название наиболее похожего товара второго каталога.
- Числовую оценку семантического сходства.

### 2.5. Визуализация результатов

С использованием Matplotlib и Seaborn формируется гистограмма распределения оценок сходства.

Визуализация позволяет исследовать результаты алгоритма и распределение значений сходства между найденными парами.

### 2.6. Экспорт результатов

Система сохраняет:

- Сгенерированные каталоги в CSV.
- Векторные представления в NumPy.
- Результаты сопоставления в CSV.
- Гистограмму распределения сходства в PNG.

## 5. Алгоритм сопоставления

### Этап 1. Подготовка данных

Генерируются два каталога товаров с названиями, описаниями и характеристиками.

### Этап 2. Формирование текстовых представлений

Для каждого товара объединяются основные текстовые характеристики:

```python
df["полное_описание"] = (
    df["название"] + " " +
    df["описание"] + " " +
    df["атрибуты"]
)
```

### Этап 3. Создание embeddings

С помощью SentenceTransformer формируются векторные представления товаров:

```python
вектора_Ozon = модель.encode(
    каталог_Ozon["полное_описание"].tolist(),
    convert_to_numpy=True
)

вектора_Wildberies = модель.encode(
    каталог_Wildberies["полное_описание"].tolist(),
    convert_to_numpy=True
)
```

### Этап 4. Вычисление семантического сходства

Для сравнения товаров используется функция `cosine_similarity`:

```python
сходства = cosine_similarity(
    вектора_Ozon,
    вектора_Wildberies
)
```

### Этап 5. Поиск соответствий

Для каждого товара первого каталога определяется позиция второго каталога с максимальным значением косинусного сходства:

```python
индекс_лучшего = np.argmax(сходства[i])
лучший_балл = сходства[i][индекс_лучшего]
```

Алгоритм возвращает наиболее похожую товарную позицию и её оценку сходства.

### Этап 6. Сохранение и визуализация

Результаты экспортируются в CSV, а распределение оценок сходства визуализируется в виде гистограммы.

## 7. Установка и запуск

### Требования

- Python 3.
- Библиотеки для обработки данных и машинного обучения.
- Локально доступная модель SentenceTransformer.

### Установка зависимостей

```bash
pip install pandas numpy torch sentence-transformers scikit-learn matplotlib seaborn
```

### Настройка модели

В файле `projet.py` необходимо указать путь к локальной модели SentenceTransformer:

```python
путь_к_модели = "путь/к/локальной/модели"
модель = SentenceTransformer(путь_к_модели)
```

Модель должна быть предварительно загружена и доступна по указанному пути.

### Запуск проекта

```bash
python projet.py
```

После выполнения скрипта формируются каталоги, embeddings, результаты сопоставления и график распределения сходства.
