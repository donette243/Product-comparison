 # Сопоставление товаров из разных каталогов с использованием BERT
 
 # Описание проекта

Данный проект демонстрирует, как с помощью моделей BERT и поиска по косинусному сходству можно автоматически находить совпадающие товары в двух разных каталогах. 
Это полезно, например, для объединения товарных баз данных между различными платформами.

# Цель

- Генерация описаний товаров для двух магазинов (Ozon и Wildberries)
- Построение эмбеддингов товаров с помощью SentenceTransformer (локальная модель BERT)
- Вычисление косинусного сходства между товарами
- Определение наиболее похожих пар товаров
- Визуализация результатов в виде гистограммы
- Сохранение данных в CSV и PNG

# Используемые технологии

- Python, Pandas, NumPy — генерация и обработка данных
- SentenceTransformers — генерация эмбеддингов с помощью BERT
- Scikit-learn — расчет косинусного сходства
- Matplotlib, Seaborn — визуализация

# Структура проекта

проект:

1. projet.py # Основной скрипт сопоставления
2. каталог_Ozon.csv # Сгенерированный каталог Ozon
3. каталог_Wildberies.csv # Сгенерированный каталог Wildberries
4. вектора_Ozon.npy # Эмбеддинги товаров Ozon
5. вектора_Wildberies.npy # Эмбеддинги товаров Wildberries
6. совпадения_товаров.csv # Результаты сопоставления
7. Распределение сходства.png # График распределения схожести
8. bert_modele # Локальная модель

# Запуск проекта
1. Установить зависимости: pip install pandas numpy matplotlib seaborn scikit-learn sentence-transformers
2. Подготовить директорию с моделью BERT (bert_modele/)

# Результат

1. каталог_Ozon.csv и каталог_Wildberies.csv — сгенерированные товары
2. совпадения_товаров.csv — пары совпавших товаров
3. Распределение сходства.png — гистограмма распределения сходства
